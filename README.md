# Synoptique régie

Éditeur de synoptiques réseau pour le spectacle, en une seule page HTML (aucune installation, aucune dépendance).

Bibliothèque : grandMA3, Luminex GigaCore et LumiNode, Netgear, Novastar (processeurs et CVT), Resolume, ArKaos, Pioneer DJ, Showkontrol.

Liaisons typées : Art-Net, sACN, MA-Net3, Ethernet, fibre (pointillé ou plein), DMX, vidéo, audio, Pro DJ Link.

Exports : SVG, PNG et projet `.json`. Le plan est sauvegardé dans le navigateur.

Ouvrir `index.html` dans un navigateur.
